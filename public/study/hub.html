Latency (মাত্রাটা মনে রাখুন, হুবহু সংখ্যা নয়)মোটামুটি
L1 cache~1 ns

Memory থেকে 1 MB sequential পড়া~250 µs

CDNStatic content-এর দূরত্বখরচ, invalidation

Rate limiterAbuse, খরচ, overloadDistributed counter-এ race আর sync

ConsistencyAvailability / latencyপুরনো data দেখালে ক্ষতি কতটা? (টাকা বনাম like count)

ReplicationErasure codingদ্রুত পড়া নাকি কম জায়গা?
Batch বড়Batch ছোটThroughput নাকি latency?
MonolithMicroserviceTeam কত বড়? আলাদা scale বা release লাগে?

সাধারণ ফাঁদ

ফাঁদবদলে
প্রশ্ন না করেই design শুরুপ্রথম ৫ মিনিট শুধু scope; ধরে নেওয়া কথা জোরে বলুন
শুরুতেই microservice, Kafka, Kubernetesসহজ design থেকে শুরু, সমস্যা দেখিয়ে তবে component যোগ (Part ১-এর গল্প)
"Cache দেব" বলে থেমে যাওয়াকী cache, key কী, TTL কত, invalidation কীভাবে, cache পড়লে কী
Single point of failure চোখ এড়ানোপ্রতিটা box-এর জন্য জিজ্ঞেস করুন: এটা পড়লে কী হয়?
Retry আছে কিন্তু idempotency নেইপ্রতিটা retry-যোগ্য write-এ idempotency key বা dedupe
DB আর queue-তে আলাদা আলাদা লেখাTransactional outbox
গড় latency দেখাp99 দেখুন
টাকা float-এInteger (পয়সায়) বা decimal string
একটা সঠিক উত্তর খোঁজাদুটো বিকল্প, প্রতিটার দাম, তারপর এই requirement-এ কেন এটা
